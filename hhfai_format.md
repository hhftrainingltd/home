# HHFAI Format

Use this format when the user asks for the same HHF AI / premium training website style.

## Overall Look

- Premium, modern education and AI consultancy design.
- Soft pale-blue and white surfaces with subtle teal and royal-blue accents.
- Calm, professional, high-trust visual tone.
- Avoid harsh dark blocks unless text is explicitly white and highly readable.
- Avoid oversized text that feels cropped, crowded, or aggressive.
- Design should feel spacious, structured, polished, and easy to scan.

## Colour Treatment

- Main background: `#f7fbff`, `#edf6ff`, `#f8fbff`, soft white-blue gradients.
- Premium cards/panels: white to pale blue gradients.
- Accent blue: `#1d4ed8`.
- Accent teal: `#0f766e`, `#14b8a6`.
- Main text: `#111827`.
- Supporting text: `#263a57`, `#334155`, `#667085`.
- Borders: light blue, usually `rgba(147, 197, 253, 0.6-0.8)`.
- Shadows: soft, wide, low-opacity navy/black shadows.

## Typography

- Use strong headings, but keep them smooth and proportional.
- Section headings should usually use:
  - `font-size: clamp(2rem, 3.6vw, 3.55rem)`
  - `line-height: 1.04`
  - `font-weight: 950`
  - subtle or zero letter spacing.
- Do not make normal section headings hero-sized.
- Hero/contact headline can be larger, but should not overflow or dominate awkwardly.
- Supporting text should be readable and premium:
  - `font-size: clamp(1.02rem, 1.25vw, 1.16rem)`
  - `line-height: 1.62`
  - `font-weight: 620-760`.

## Section Header Cards

Use premium section header panels for major sections:

- Rounded corners: `22px-26px`.
- Background: white to pale-blue gradient.
- Border: soft blue.
- Box shadow: soft and spacious.
- Padding: around `32px 34px` desktop, `24px` mobile.
- Include a pill label above the heading.
- Heading and supporting paragraph should align visually with the cards below.
- Header cards must blend with their following card grid; avoid making them look like unrelated hero panels.

## Pill Labels

- Uppercase.
- Rounded pill shape.
- Pale blue fill.
- Blue text.
- Strong weight.
- Example style:
  - `padding: 10px 20px`
  - `border-radius: 999px`
  - `background: rgba(219, 234, 254, 0.86)`
  - `color: #1d4ed8`
  - `border: 1px solid rgba(147, 197, 253, 0.92)`
  - `font-weight: 950`
  - `letter-spacing: 0.10em`.

## Cards

All feature cards should feel consistent:

- White or very pale blue gradient.
- `border-radius: 18px-22px`.
- Soft blue border.
- Soft shadow.
- Thin top accent bar using blue/teal gradient.
- Optional pale blue circular highlight in the corner.
- Card headings should be bold but not huge.
- Supporting text should be readable, medium weight, and not too light.

Do not change already-approved service cards unless the user explicitly asks.

## Process / Journey Sections

For “From first conversation to measurable improvement” style process sections:

- Use the same premium header card style as the other sections.
- Heading size should match ordinary section headers, not hero headings.
- Journey cards can be horizontal on desktop.
- Use subtle connector lines/arrows only when they do not clutter.
- On tablet/mobile, stack cleanly.

## Services Header

If the services area has a darker background:

- Heading and supporting text must be white.
- Supporting text can be `rgba(255,255,255,0.92)`.
- The service card grid below should remain untouched if already approved.
- Do not use the word “Seven” in the services heading unless requested.

Preferred heading:

`Specialist services designed for the AI era.`

## Contact / CTA Section

Contact section should be premium but smooth:

- Do not make the contact headline excessively large.
- Keep contact details refined and readable.
- Two-column layout on desktop:
  - Left: label, heading, supporting copy, CTA buttons.
  - Right: contact rows.
- Right panel can use a pale blue/teal background.
- Contact row labels should be uppercase teal.
- Contact values should be clear, but not oversized.
- Mobile: stack into one column.

## Navigation

- Premium pill-style navigation.
- Soft translucent white/blue background.
- Rounded menu container.
- Strong but compact nav links.
- CTA button should use blue/teal gradient.
- Avoid duplicate nav items or malformed list items.

## Responsive Rules

- Ensure text never overflows cards or buttons.
- Section headings should scale down on mobile.
- Cards stack cleanly on mobile.
- Contact rows become single-column on mobile.
- Avoid viewport-scaled typography that gets cartoonishly large.
